# Claude Hub

Um espaço em português para compartilhar atualizações, dicas, skills e projetos com Claude.

## O que você vai encontrar

- **Atualizações:** novidades e registros de evolução dos conteúdos e projetos.
- **Dicas:** aprendizados, exemplos de prompts e formas práticas de usar o Claude.
- **Skills:** instruções e recursos reutilizáveis para tarefas específicas.
- **Projetos:** experimentos, automações e aplicações desenvolvidas com apoio do Claude.

## Organização sugerida para novos conteúdos

Ao adicionar arquivos, use as pastas abaixo conforme o assunto:

| Pasta | Conteúdo |
| --- | --- |
| `atualizacoes/` | Notas e novidades, com data e links de referência. |
| `dicas/` | Tutoriais curtos, prompts e exemplos de uso. |
| `skills/` | Uma pasta por skill, com instruções de uso. |
| `projetos/` | Uma pasta por projeto, com seu próprio README. |

As pastas podem ser criadas ao publicar o primeiro arquivo de cada categoria.

## Como publicar pelo GitHub

1. Na página principal, clique em **Add file**.
2. Escolha **Create new file** para escrever ou **Upload files** para enviar arquivos.
3. Para criar uma pasta, inclua o caminho no nome do arquivo, como `dicas/primeira-dica.md`.
4. Escreva uma mensagem resumindo a atualização e confirme em **Commit changes**.

Em cada conteúdo, procure explicar o objetivo, os passos de uso e apresentar um exemplo.

## Ideias e contribuições

Use as **Issues** para sugerir conteúdos ou relatar problemas e os **Pull requests** para propor melhorias.
